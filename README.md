# 📄 AI Resume Builder

An intelligent Resume Builder web application built with Django that helps users create professional resumes efficiently through an easy-to-use interface and downloadable PDF formats.

## 🚀 Features

- 🔐 User Authentication & Authorization
- 👤 Profile Management
- 📄 Resume Creation & Editing
- 🎨 Multiple Resume Templates
- 📥 PDF Resume Download
- 💼 Work Experience Management
- 🎓 Education Details Management
- 🛠 Skills & Certifications Section
- 📱 Responsive Design
- ⚙️ Admin Dashboard

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/resume-builder.git
cd resume-builder
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux/macOS

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Migrations

```bash
python manage.py migrate
```

### Start Server

```bash
python manage.py runserver
```
